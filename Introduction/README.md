# 💻 Introduction to JavaScript

## 🌟 What is JavaScript?

**JavaScript is a programming language used to make websites interactive.**

For example, JavaScript can make a website:

- 🖱️ Respond when we click a button
- 💬 Show a message or popup
- 📝 Check a form before submitting
- 🎨 Change content on a webpage
- 🔄 Update information without refreshing the page
- ✨ Add animations and effects

### Simple Example

```javascript
console.log("Hello, JavaScript!");
```

This displays:

```text
Hello, JavaScript!
```

`console.log()` is used to display something in the console.

---

# 🌐 HTML, CSS and JavaScript

A simple way to understand them is to think about a **house** 🏠.

| Technology | What it does | Think of it as |
|---|---|---|
| HTML | Creates the structure | 🧱 Structure |
| CSS | Makes it look good | 🎨 Design |
| JavaScript | Makes it work and respond | ⚡ Behaviour |

### Easy Example

**HTML** → Creates a button.

**CSS** → Makes the button beautiful.

**JavaScript** → Makes something happen when we click it.

So remember:

> **HTML = Structure**  
> **CSS = Style**  
> **JavaScript = Behaviour**

---

# 🤔 Why Do We Use JavaScript?

We use JavaScript to make websites **useful and interactive**.

For example:

- Clicking buttons
- Opening menus
- Validating forms
- Creating sliders
- Showing or hiding content
- Calculating values
- Getting data from a server
- Building web applications

Without JavaScript, many websites would mostly be **static**, meaning they would display information but have little interaction.

---

# 🌍 Where is JavaScript Used?

JavaScript is not only used for websites.

## 💻 1. Frontend Development

JavaScript runs in the browser and controls what users see and interact with.

Examples:

- Buttons
- Forms
- Menus
- Search
- Animations
- Dashboards

Popular JavaScript technologies:

- React
- Angular
- Vue
- Next.js

---

## ⚙️ 2. Backend Development

JavaScript can also run on the **server** using **Node.js**.

The backend handles things that happen behind the scenes.

For example:

- Login
- User registration
- APIs
- Database operations
- Sending and receiving data

### Simple idea:

```text
Frontend → User sees and interacts
Backend  → Server processes the request
Database → Stores the data
```

---

## 📱 3. Mobile Applications

JavaScript can also be used to create mobile applications.

For example:

**React Native** can be used to build Android and iOS applications.

---

## 🖥️ 4. Desktop Applications

JavaScript can also be used to create desktop applications.

For example:

**Electron** is a technology used to build desktop applications using web technologies.

# 🧠 Important Terms

### Programming Language

A programming language is a way of giving instructions to a computer.

Examples:

- JavaScript
- Python
- Java
- C++

### Browser

A browser is software used to access websites.

Examples:

- Chrome
- Edge
- Firefox

JavaScript can run inside modern web browsers.

### Node.js

**Node.js allows JavaScript to run outside the browser**, especially on servers.

# 🎤 Basic Interview Questions

### 1. What is JavaScript?

JavaScript is a programming language used mainly to make websites interactive and dynamic.

### 2. Why do we use JavaScript?

We use JavaScript to add functionality and interactivity to websites.

### 3. What is the difference between HTML, CSS and JavaScript?

**HTML** creates the structure, **CSS** styles it, and **JavaScript** adds behaviour.

### 4. Can JavaScript be used for backend development?

Yes. JavaScript can be used for backend development with Node.js.

### 5. What is Node.js?

Node.js is a runtime environment that allows JavaScript to run outside the browser.

### 6. Where is JavaScript used?

JavaScript is used in websites, web applications, backend systems, mobile applications, and desktop applications.
