# ⚙️ Operators in JavaScript

## 🌟 What is an Operator?

An operator is a **symbol used to perform an operation on values**.

---

## ➕ 1. Arithmetic Operators

Arithmetic operators are used to **perform calculations**.

```text
+  → Addition
-  → Subtraction
*  → Multiplication
/  → Division
%  → Remainder
```

---

## 📝 2. Assignment Operators

Assignment operators are used to **assign or update values**.

```text
=   → Assign
+=  → Add and assign
-=  → Subtract and assign
*=  → Multiply and assign
/=  → Divide and assign
```

---

## 🔍 3. Comparison Operators

Comparison operators are used to **compare values** and return `true` or `false`.

```text
==   → Equal value
===  → Equal value and type
!=   → Not equal
!==  → Not equal value or type
>    → Greater than
<    → Less than
>=   → Greater than or equal
<=   → Less than or equal
```

### ⭐ `==` vs `===`

> `==` compares only the **value**, while `===` compares both the **value and data type**.

```text
==   → Compares value
===  → Compares value and data type

```

## 🧠 4. Logical Operators

Logical operators are used to **combine or reverse conditions**.

```text
&&  → AND
||  → OR
!   → NOT
```

* `&&` → Both conditions must be true.
* `||` → At least one condition must be true.
* `!` → Reverses the result.

---

## 🔄 5. Increment and Decrement Operators

These operators are used to **increase or decrease a value by 1**.

```text
++  → Increase by 1
--  → Decrease by 1
```

---

## ⭐ Remember

**Arithmetic → Calculate**

**Assignment → Assign or update**

**Comparison → Compare**

**Logical → Combine conditions**

**Increment/Decrement → Increase or decrease by 1**
