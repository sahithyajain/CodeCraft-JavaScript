# 📘 Data Types in JavaScript

## 🌟 What is a Data Type?

A data type tells us **what kind of value** a variable stores.


## 📚 Common Data Types

### 1. String

A string is **text written inside quotes**.

```javascript
let name = "Sahithya";
```

### 2. Number

A number stores **integer or decimal values**.

```javascript
let age = 22;
let price = 99.5;
```

### 3. Boolean

A boolean stores only **`true` or `false`**.

```javascript
let isStudent = true;
```

### 4. Undefined

`undefined` means a variable has been declared but **has not been given a value**.

```javascript
let city;
```

### 5. Null

`null` means we **intentionally set the value to nothing**.

```javascript
let result = null;
```

### 6. Object

An object stores **multiple related values as key-value pairs**.

```javascript
let person = {
    name: "Sahithya",
    age: 22
};
```

### 7. Array

An array stores **multiple values in a single variable**.

```javascript
let fruits = ["Apple", "Mango", "Orange"];
```

---

## 🔍 `typeof`

`typeof` is used to **find the data type of a value**.

```javascript
let age = 22;

console.log(typeof age);
```

Output:

```text
number
```
